## 🔗 关于"GitHub 上点击预览 HTML"

GitHub 默认只显示 HTML 源码不渲染。下面三种方式任选其一即可在浏览器看渲染效果:

1. **raw.githack(推荐)**:把 `https://github.com/<user>/<repo>/blob/<branch>/<path>` 改成 `https://raw.githack.com/<user>/<repo>/<branch>/<path>`
2. **htmlpreview**:在 GitHub 文件页 URL 前拼一个 `https://htmlpreview.github.io/?`
3. **GitHub Pages**:仓库 Settings → Pages 开启后 URL 形如 `https://<user>.github.io/<repo>/<path>`
